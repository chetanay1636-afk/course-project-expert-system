# Course Project Recommendation Expert System

## Description

This project is a rule-based expert system developed using HTML, CSS, and JavaScript.

The system helps students choose suitable academic projects according to their interests and technical skills.

The software uses IF-THEN rules and forward chaining concepts from Artificial Intelligence.

---

## Features

- Detailed project recommendations
- Technologies required
- Websites to explore
- Implementation steps
- Difficulty levels
- Responsive user interface

---

## Technologies Used

- HTML
- CSS
- JavaScript

## AI Concepts Used

- Knowledge Representation

- Rule-Based System

- Expert System

## How to Run

1. Open the project folder in Visual Studio Code.
2. Install Live Server extension.
3. Open INDEX.HTML.
4. Right-click and select:
   Open with Live Server
